# RamPyare Trader
Voice-based shop management (stock, billing, customer due, WhatsApp bill, PDF/Excel export).

## GitHub se APK banana
1. Naya repo banao aur is poore folder ko push karo (`.github` folder bhi).
2. Repo > Actions > "Build APK" automatically chalega (ya "Run workflow" dabao).
3. Run khatam hone par Artifacts > **RamPyareTrader-apk** download karo, zip kholo, `app-debug.apk` phone mein install karo.
4. Release ke liye tag lagao: `git tag v1.0 && git push origin v1.0` - APK Releases page par aa jayega.
